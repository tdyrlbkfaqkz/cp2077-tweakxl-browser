## Overview

Cyberpunk 2077 TweakXL Config Browser provides a searchable GUI for browsing and editing TweakXL mod configuration files, presenting the nested YAML structure as a readable tree with inline editing, search across all installed TweakXL mods, and syntax validation before saving changes.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Cyberpunk 2077 TweakXL Config Browser** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Config Tree** | Renders TweakXL YAML configuration as a navigable tree view |
| **Global Search** | Search across all installed TweakXL mod configs simultaneously |
| **Inline Edit** | Edit any configuration value directly in the tree without a text editor |
| **Validation** | Validates YAML syntax and TweakXL schema before writing changes |
